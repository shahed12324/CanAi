# Jarvis One — MCP সার্ভার

আপনার Jarvis ওয়ার্কফ্লো যেকোনো MCP-সমর্থিত AI অ্যাপ থেকে টুল হিসেবে ব্যবহার করা যায়।

- **ঠিকানা:** `POST https://<আপনার-ডোমেইন>/api/public/v1/mcp` (প্রতি অনুরোধে একটি JSON-RPC বার্তা; উত্তর JSON; ব্যাচ নেই)
- **হেডার:** `Authorization: Bearer jk_live_…` — ডেভেলপার পেজ থেকে বানানো API কী। যেকোনো বৈধ কী সংযোগ করতে পারে; প্রতিটি টুলের নিজস্ব স্কোপ লাগে।
- **প্রোটোকল:** `2025-06-18`; মেথড: `initialize`, `ping`, `tools/list`, `tools/call`।

| টুল | স্কোপ | কাজ |
|---|---|---|
| `list_workflows` | `workflows:read` | আমার ওয়ার্কফ্লো ও তাদের ইনপুটের নাম |
| `run_workflow` | `workflows:run` | চালু ওয়ার্কফ্লো চালানো; `dry_run: true` দিলে শুধু ইনপুট যাচাই, কিছু শুরু বা খরচ হয় না |
| `get_run` | `workflows:read` | রানের অবস্থা ও খরচ |
| `get_credits` | `credits:read` | ক্রেডিট ব্যালেন্স |

`tools/list` শুধু কী-এর স্কোপ অনুযায়ী টুল দেখায়। অনুমোদন দেওয়া, মোছা, কী বদলানো বা টাকা সংক্রান্ত কোনো টুল নেই। বাইরে পাঠানোর ধাপ আগের মতোই ব্যক্তির অনুমোদনের অপেক্ষায় থাকে।

REST এ একই `dry_run` আছে: `POST /workflows/{id}/run` বডিতে `{"dry_run": true}` → `{"data":{"dry_run":true,"ok":true}}`।
