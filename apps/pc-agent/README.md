# JARVIS ONE — কম্পিউটার এজেন্ট

আপনার **পিসি, ল্যাপটপ বা VPS**-এ বসে সার্ভার থেকে *অনুমোদিত* কাজ টেনে এনে চালায়। কোনো পোর্ট খোলে না (শুধু বাইরে যায়)। Python ৩.৯+, কোনো বাইরের প্যাকেজ লাগে না (`psutil` থাকলে স্বাস্থ্য-তথ্য ভালো হয়)।

## ইনস্টল
```bash
pip install ./apps/pc-agent          # বা:  pip install "./apps/pc-agent[metrics]"
```
Windows-এ একই (Python ইনস্টল করে `pip install …`)। VPS-এ আলাদা ইউজার দিয়ে চালানো ভালো।

## ৩ ধাপে চালু
1. ওয়েবে **আমার কম্পিউটার → জোড়া দিন** — এককালীন কোড দেখাবে (১০ মিনিট)।
2. `jarvis-agent pair --server https://আপনার-ডোমেইন --code কোড`
3. **এই মেশিনের নিয়ম** ঠিক করুন (শুরুতে কোনো ফোল্ডারই অনুমোদিত নয়):
   ```bash
   jarvis-agent policy add-root /home/me/work        # যে ফোল্ডারে কাজ চলবে
   jarvis-agent policy show
   ```
4. `jarvis-agent run` (পরীক্ষার জন্য `--once`)

## দুই স্তরের নিরাপত্তা
সার্ভার আগে সিদ্ধান্ত নেয় (আপনার ওয়েব-নিয়ম, অনুমোদন, জরুরি স্টপ, উচ্চ-ঝুঁকিতে ফোনে পিন)। তারপর **এই মেশিন আবার নিজে যাচাই করে** — সার্ভার ভুল/হ্যাক হলেও:
- ফোল্ডার: শুধু `policy add-root`-এর ভেতরে; symlink ও `..` ধরে বেরোনো আটকানো; পুরো ড্রাইভ/`/` অনুমোদিত হয় না।
- ধরন: শুরুতে শুধু `read_file`, `list_dir`, `write_file`। বাকিগুলো নিজে চালু করতে হয়: `jarvis-agent policy enable delete_file|run_command|open_app|browser_navigate`।
- কমান্ড/অ্যাপ: শুধু `policy add-command`/`add-app`-এর নামের তালিকা; কোনো shell নেই, আর্গুমেন্ট আক্ষরিক; ৩০ সেকেন্ডে থামে।
- ওয়েবসাইট: শুধু https ও `policy add-host`-এর সাইট (সাবডোমেইনসহ)।
- `power`, `input_control`, `system_setting` এই সংস্করণে **নেই** (বন্ধ — "সমর্থিত নয়" জানায়)।
- টোকেন `config.json`-এ (ফাইল-অনুমতি ০৬০০)। সার্ভারে ডিভাইস সরালে এজেন্ট নিজে থেমে যায় (exit 2)।
- সার্ভারের ঠিকানা https ছাড়া নেয় না (শুধু localhost, বা নিজের দায়ে `--allow-http`)।

## সার্ভিস হিসেবে চালানো
```bash
jarvis-agent service systemd   # unit ফাইল ছাপে → /etc/systemd/system/jarvis-agent.service এ রাখুন
jarvis-agent service windows   # Task Scheduler-এর কমান্ড ছাপে
```
(কিছু নিজে ইনস্টল করে না — ছাপা লেখা দেখে আপনি বসান।)

## জানালা (`jarvis-agent gui`)
> 0.129.0 থেকে জানালাটি ১৪-মেনুর নতুন প্রিমিয়াম UI (`jarvis_agent/ui/`)। নিচের বর্ণনা মূল তিন ট্যাবের (হোম/নিয়ম/ইতিহাস) — সেগুলো এখন "হোম", "সেটিংস ও নিরাপত্তা", "কাজের ইতিহাস" নামে আছে। বিস্তারিত: `docs/DESKTOP_ARCHITECTURE.md`, `docs/DESKTOP_API.md`।

কমান্ডটি শুধু `127.0.0.1`-এ একটি পাতা চালু করে ও ব্রাউজারে খোলে: **হোম** (জোড়া/চালু-বন্ধ, প্রসেসর-মেমরি-ডিস্ক), **নিয়ম** (ফোল্ডার/সাইট/অ্যাপ/কমান্ড যোগ-সরানো, কাজের ধরনের সুইচ), **ইতিহাস** (এই কম্পিউটারে কী চলল/বাতিল হলো, সর্বশেষ ২০০টি)। জোড়া না থাকলে পেয়ারিং ফর্ম দেখায়। জানালা অনুমোদন দিতে পারে না — অনুমোদন সার্ভার/ফোনে। সুরক্ষা: প্রতি রানে এলোমেলো টোকেন (URL-এর `#` অংশে, হেডারে যায়), Host ও Origin যাচাই, কঠোর CSP, ৮ কেবি বডি-সীমা। কমান্ড-লাইনের সঙ্গে একই নিয়ম-মডিউল (`policy.py`) ব্যবহার করে।

## আসল সার্ভারের সঙ্গে যাচাই (আপনার সার্ভারে)
আমি এখানে Laravel বসাতে পারিনি (Composer/GitHub ডাউনলোড ব্লক), তাই এজেন্ট নকল-সার্ভারে যাচাই। আসল সার্ভারে: ১) ওয়েবে "আমার কম্পিউটার" → জোড়া দেওয়ার কোড নিন ২) `jarvis-agent gui` (বা `pair --server https://… --code …`) ৩) নিয়মে একটি ফোল্ডার যোগ করুন ৪) ওয়েব/ফোন থেকে `read_file` অনুরোধ + অনুমোদন ৫) জানালার ইতিহাসে ও ওয়েবে ফল দেখুন ৬) উচ্চ ঝুঁকির কাজ (`ফাইল মোছা`) ফোনে পিনসহ অনুমোদন করে দেখুন। কিছু না মিললে `curl -H "Authorization: Bearer <token>" https://…/api/pc/v1/actions/next` দিয়ে প্রোটোকল দেখুন।

## সীমা
- সার্ভার ফল সর্বোচ্চ ২০০০ অক্ষর রাখে; `read_file` শুরুর ~১৯০০ অক্ষর দেয়।
- ট্রে-আইকনসহ Tauri অ্যাপ `apps/desktop`-এ (Linux-এ যাচাই; Windows/macOS-এ CI-এর অপেক্ষায়)।
- Windows-এ আসল চালানো এখানে যাচাই হয়নি (Linux-এ ৯০ টেস্ট + ১৫-ধাপের আসল-Chrome e2e (`tests/e2e/gui.e2e.cjs`); নিয়মগুলো Windows পথের জন্যও লেখা)।
