# লোকাল ওয়ার্কার (ঐচ্ছিক) — নিজের কম্পিউটারে Ollama

**কী কাজ করে:** আপনার কম্পিউটারে চলা Ollama মডেলকে JARVIS-এ একটি সাধারণ AI Provider হিসেবে যোগ করা যায় (engine-এ `ollama` adapter আগে থেকেই আছে, লোকাল/প্রাইভেট ঠিকানা শুধু অ্যাডমিন-অনুমোদিত provider-এ চলে)। এতে ক্লাউড API খরচ কমে।

**কী এখনও নেই (সততার সাথে):** FFmpeg রেন্ডার কাজ আপনার কম্পিউটারে পাঠানোর প্রোটোকল তৈরি হয়নি — ভিডিও রেন্ডার সার্ভারের engine কন্টেইনারেই (ffmpeg সহ) চলে। ডেস্কটপ অ্যাপ (Tauri) থেকে ওয়ার্কার চালু/বন্ধ করা Phase 25-এর অংশ।

## ধাপ
1. নিজের কম্পিউটারে Ollama ইনস্টল করুন (https://ollama.com/download) অথবা এই ফোল্ডারে `docker compose up -d`।
2. `./setup.sh llama3.2` — মডেল নামায় ও প্রয়োজনীয় সেটিং দেখায়।
3. সার্ভার থেকে আপনার কম্পিউটারে পৌঁছানো:
   - **সহজ ও নিরাপদ: Tailscale** — দুই জায়গাতেই Tailscale চালান; base URL হবে `http://100.x.y.z:11434/v1` (আপনার কম্পিউটারের Tailscale IP)। Ollama-কে `OLLAMA_HOST=100.x.y.z:11434` বা localhost-এ বেঁধে রাখুন; ইন্টারনেটে খুলবেন না (Ollama-র নিজস্ব লগইন নেই)।
   - **একই মেশিন/VPS-এ Ollama:** base URL `http://host.docker.internal:11434/v1` (compose-এ `extra_hosts` দেওয়া আছে)।
4. `/admin → AI Provider` → type `ollama` → base URL → "allow private" চালু → Test → মডেল যোগ (দাম ০ হতে পারে) → চালু।

## নিরাপত্তা
- Ollama পোর্ট `0.0.0.0`-এ বা পাবলিক IP-তে খুলবেন না।
- প্রাইভেট ঠিকানা শুধু প্ল্যাটফর্ম অ্যাডমিন যোগ করা provider-এ চলে; ক্লাউড মেটাডাটা ঠিকানা সবসময় বন্ধ।
